# Allowed Tasks

The agent may work on tasks inside this Deep Agent Template project, including:

- Reading and explaining the current codebase.
- Implementing project features, tests, prompts, guardrails, tools, package exports, and documentation.
- Adapting referenced examples or research to this repository's architecture.
- Running non-destructive checks, tests, formatting, and type checking.
- Creating or updating markdown-controlled policies, prompts, and project scaffolding.
- Summarizing findings, risks, and verification results for the user.
